Python pip 与 conda 源设置：新手一次配好

第一章：为什么安装总是很慢

默认的软件源在海外，网络不稳时下载缓慢甚至失败。更换到较近的镜像，是最直接的办法。

第二章：pip 的设置

可以通过命令设置全局镜像地址，也可以在单次安装时用参数指定。配置写入用户目录下的配置文件，之后所有安装都会使用它。

第三章：conda 的设置

在配置文件里添加镜像频道，并设置频道优先级。遇到解析依赖很慢时，可以尝试更新到较新的求解器。

第四章：养成虚拟环境的习惯

  • 每个项目一个独立环境，互不影响。
  • 用文件记录依赖版本，方便他人复现。
  • 出问题时，删掉环境重建比反复修补更快。

第五章：需要代理时

在命令行里设置代理环境变量，或在 pip 参数里指定。公司内部的包仓库要设置为不走代理。

结语

花十分钟配好，后面省下几十个小时。
